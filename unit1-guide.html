คู่มือฝึกปฏิบัติ Python หน่วยที่ 1

สำหรับนักเรียน ปวช.2 · สัปดาห์ที่ 1–2 (8 คาบ) · เริ่มจากศูนย์ได้

เป้าหมาย: เปิดโปรแกรม พิมพ์คำสั่ง print() แสดงข้อความ 3 บรรทัด อ่านข้อผิดพลาดง่าย ๆ และเก็บหลักฐานงานได้

คู่มือนี้ใช้ได้เมื่อเปิดไฟล์เว็บไซต์จากเครื่อง แต่การใช้ Programiz ต้องเชื่อมต่ออินเทอร์เน็ต

1. เริ่มต้นกับ Programiz ทีละขั้น

  1. เชื่อมต่ออินเทอร์เน็ต แล้วเปิด Programiz Online Python Compiler
  2. มองหาช่องเขียนโค้ด (Editor) และปุ่ม Run บนหน้าเว็บ ตำแหน่งอาจเปลี่ยนตามการปรับปรุงเว็บไซต์
  3. คลิกในช่องเขียนโค้ด ลบโค้ดตัวอย่างที่ไม่ต้องการ แล้วพิมพ์โค้ดด้านล่างด้วยตนเอง
  4. คลิก Run แล้วดูข้อความที่ช่องผลลัพธ์ (Output)
  5. ถ้าผลลัพธ์ไม่ตรง ให้ตรวจตัวสะกด วงเล็บ และเครื่องหมายอัญประกาศ แล้ว Run ใหม่
ตัวอย่าง
print("สวัสดีค่ะ")
print("ฉันกำลังเรียน Python")
print("ฉันทำได้")
ผลลัพธ์ที่คาดหวัง
สวัสดีค่ะ
ฉันกำลังเรียน Python
ฉันทำได้

หมายเหตุ: หน้านี้เป็นคู่มือข้อความ ไม่ใช่ภาพหน้าจอจริงของ Programiz เพื่อไม่ให้สับสนหากเว็บไซต์เปลี่ยนรูปแบบ

2. ใบงานปฏิบัติ 1 — โปรแกรมแนะนำตัวเอง

เขียน print() 3 บรรทัด แสดง (1) ชื่อเล่น (2) สิ่งที่ชอบ (3) อาชีพที่อยากทำ โดยใช้ข้อความของตนเอง ห้ามคัดลอกข้อมูลตัวอย่างทั้งหมด
print("ชื่อเล่นของฉันคือ ...")
print("ฉันชอบ ...")
print("อาชีพในฝันคือ ...")

ตรวจตนเอง: มีครบ 3 บรรทัด · Run ได้ · ผลลัพธ์ตรงกับข้อความที่ตั้งใจ · ใช้ข้อความของตนเอง

3. ใบงานปฏิบัติ 2 — นักสืบแก้ Error

พิมพ์โค้ดแต่ละข้อที่ผิดลงใน Programiz สังเกตข้อความ Error แล้วแก้ให้ Run ได้

ข้อ 1
pritn("Hello")
print("Hello")
# สะกดชื่อคำสั่ง print ให้ถูกต้อง
ข้อ 2
print("Python)
print("Python")
# เพิ่มเครื่องหมายอัญประกาศปิดข้อความ
ข้อ 3
print("I can code"
print("I can code")
# เพิ่มวงเล็บปิด

เมื่อเจอ Error ให้ดูบรรทัดที่โปรแกรมชี้ ตรวจการสะกดและสัญลักษณ์ก่อน แล้วค่อยกด Run ใหม่

4. เก็บไฟล์และหลักฐานผลงาน

  1. เก็บโค้ดเป็นไฟล์นามสกุล .py เช่น unit1_myname.py โดยคัดลอกโค้ดไปวางในโปรแกรมแก้ไขข้อความ แล้วเลือกบันทึกเป็น UTF-8 และชื่อไฟล์ลงท้าย .py
  2. หาก Programiz มีตัวเลือกดาวน์โหลดหรือบันทึก ให้ตรวจชนิดไฟล์และเนื้อหาที่ได้จริงก่อนใช้
  3. จับภาพหน้าจอที่เห็นโค้ดและผลลัพธ์ด้วย Windows + Shift + S แล้วบันทึกภาพเป็น PNG หรือ JPG
  4. เปิดไฟล์ .py อีกครั้งเพื่อตรวจว่าโค้ดยังอยู่ครบ และตรวจว่าภาพหน้าจออ่านได้
  5. เปิด หน้าเตรียมส่งงาน เพื่อแนบไฟล์ได้สูงสุด 10 ไฟล์ตามข้อกำหนดของต้นแบบ

สำคัญ: เวอร์ชันนี้ยังไม่ส่งงานเข้า KruVanda Classroom อัตโนมัติ หน้าเตรียมส่งงานเดิมยังใช้วิธีดาวน์โหลดไฟล์ข้อมูลเพื่อส่งต่อครู

5. เมื่ออินเทอร์เน็ตใช้ไม่ได้

  1. เปิด Thonny หรือ Python IDLE ที่ครูติดตั้งไว้ล่วงหน้าในคอมพิวเตอร์
  2. เลือกสร้างไฟล์ใหม่ พิมพ์คำสั่ง print("Hello")
  3. บันทึกชื่อ unit1_offline.py ลงในโฟลเดอร์งานของตนเอง
  4. กด Run ตามโปรแกรมที่ใช้ เช่น Thonny ใช้ปุ่ม Run หรือ F5
  5. เก็บไฟล์ .py และภาพหน้าจอไว้ส่งเมื่ออินเทอร์เน็ตกลับมา

ต้องติดตั้งเครื่องมือออฟไลน์ไว้ก่อนวันที่อินเทอร์เน็ตขัดข้อง มิฉะนั้นวิธีนี้จะใช้ไม่ได้

6. แบบตรวจผลงานก่อนส่ง

เครื่องหมายถูกหน้านี้เป็นเพียงการตรวจตนเอง ไม่บันทึกเป็นคะแนนของครู

7. คำอธิบายเพิ่มเติมให้ถูกต้อง

Interpreter: ใน Python รุ่น CPython โดยทั่วไปโค้ดจะถูกแปลงเป็น bytecode ก่อนให้ Python Virtual Machine ประมวลผล จึงไม่ควรเข้าใจว่า Python ทุกแบบแปลซอร์สโค้ดเป็นภาษาเครื่องทีละบรรทัดตรง ๆ เสมอ

Dynamic typing: ไม่ต้องระบุชนิดตัวแปรล่วงหน้า ชื่อตัวแปรสามารถอ้างอิงค่าต่างชนิดได้ (รายละเอียดเรียนในหน่วยที่ 3)

เครื่องหมายอัญประกาศ: ใช้เครื่องหมายตรง " " หรือ ' ' ไม่ใช้เครื่องหมายอัญประกาศโค้งที่ Word อาจเปลี่ยนอัตโนมัติ
